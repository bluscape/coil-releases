First preview of Coil: fast ESP32 debugging and flashing over JTAG, for VS Code and Espressif-IDE, on Windows 10 and 11 (x64).

**Tested with:** ESP32-S3 and ESP32-C6 over the chip's built-in USB-JTAG, and the classic ESP32 through an ESP-Prog.

## Downloads

| File | For |
|---|---|
| `Coil-Setup-0.1.0.exe` | **Espressif-IDE.** Installs Coil per user and offers Espressif-IDE, ESP-IDF (through Espressif's installer, EIM) and the USB drivers when they're missing or out of date. Optional weekly update check. |
| `coil-0.1.0.vsix` | **VS Code**, until Coil is on the Marketplace: **Extensions → … → Install from VSIX**. Its Setup view installs ESP-IDF, the drivers and code completion. |

After installing for Espressif-IDE, set your debug configuration's OpenOCD **Executable path** to `%LOCALAPPDATA%\Programs\Coil\bin\coil-gdb.exe`. The [guide](https://coil.zone/guide/#espressif-ide) has the steps.

## Good to know

- This is a preview. Please [open an issue](https://github.com/bluscape/coil-releases/issues) with what you find.
- The programs aren't code-signed yet, so Windows SmartScreen may warn when you run the installer (**More info → Run anyway**).
