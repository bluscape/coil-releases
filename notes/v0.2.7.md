Build profiles of your own, edited in a panel instead of `settings.json` and `launch.json`, and projects from Espressif-IDE bring their build configurations along. VS Code updates the extension from the [Marketplace](https://marketplace.visualstudio.com/items?itemName=bluscape.coil) by itself.

**Tested with:** ESP32-C3, ESP32-S3 and ESP32-C6 over the chip's built-in USB-JTAG, and the classic ESP32 through an ESP-Prog. Windows 10 and 11 (x64).

## What's new

- **Build profiles of your own.** Debug, Release, a signed release, a factory build: as many as the project needs, each with its own name, build folder and defaults files. The status bar switches between them, and Build, Flash, Monitor, F5, the Settings view and Release Image follow. Each keeps its own build, so switching never rebuilds the others.
- **The Build & Debug panel** (**Coil: Edit Build & Debug Configurations**, or **Edit profiles…** in the profile picker): build profiles and debug configurations as forms, with Apply and Revert. A debug configuration picks a profile, a connected board and whether to flash first. Coil writes `.vscode/settings.json` and `.vscode/launch.json` for you, and keeps everything else in them.
- **Projects from Espressif-IDE or Espressif's VS Code extension:** Coil finds their build configurations (`sdkconfig.defaults.debug` and `build_debug`, …, or `CMakePresets.json`) and offers them as profiles in one click.
- **Secure builds:** a profile with Secure Boot or flash encryption is treated as production firmware. F5 won't debug it, and Flash asks first every time, saying what can't be undone, then flashes over serial only. Build checks the signing key is there, and the Setup view warns when the key is tracked by git.
- **`coil-config --profile`** takes any profile's name.
- **Fixed:** a build could hang when Coil's fast build followed one that had fallen back to `idf.py`.

The [guide](https://coil.zone/guide/#build-profiles) has the details.

## Downloads

| File | For |
|---|---|
| `Coil-Setup-0.2.7.exe` | **Espressif-IDE.** Installs Coil per user and offers Espressif-IDE, ESP-IDF (through Espressif's installer, EIM) and the USB drivers when they're missing or out of date. Optional weekly update check. Run it over an earlier version to update. |
| `coil-0.2.7.vsix` | **VS Code without Marketplace access:** **Extensions → … → Install from VSIX**. Everyone else: install **Coil for ESP32** from the Marketplace or Open VSX. |

After installing for Espressif-IDE, set your debug configuration's OpenOCD **Executable path** to `%LOCALAPPDATA%\Programs\Coil\bin\coil-gdb.exe`. The [guide](https://coil.zone/guide/espressif-ide/) has the steps.

## Good to know

- This is a preview. Please [open an issue](https://github.com/bluscape/coil-releases/issues) with what you find.
- The programs aren't code-signed yet, so Windows SmartScreen may warn when you run the installer (**More info → Run anyway**). Code signing is the first [Ko-fi goal](https://ko-fi.com/coilzone).
