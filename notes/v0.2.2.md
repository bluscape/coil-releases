Coil now flashes and debugs firmware that uses **light sleep**: it waits for the chip to wake, then halts it, instead of failing with "endpoint STALL". The VS Code extension's setup checks no longer hang.

**Tested with:** ESP32-C3, ESP32-S3 and ESP32-C6 over the chip's built-in USB-JTAG, and the classic ESP32 through an ESP-Prog. Windows 10 and 11 (x64).

## What's new

- **Firmware with light sleep:** while the chip sleeps, its USB-JTAG doesn't answer. Coil (coil-gdb, coil-dap and coil-flash) now keeps trying for up to 20 s and halts the chip the moment it wakes, so flashing and debugging carry on normally. Before, the first try failed, for example Espressif-IDE's "flash every time" with "board … was reset or unplugged … endpoint STALL". Tested on the ESP32-C3.
- **VS Code setup checks no longer hang** when a board's driver stops answering: every check has a time limit, a slow one shows as a warning, and an ESP-Prog held by a stuck program reads "JTAG channel in use".
- **Coil: New Source File** works in projects opened through a short (8.3) Windows path.
- **The guide** has its own pages for [VS Code](https://coil.zone/guide/), [Espressif-IDE](https://coil.zone/guide/espressif-ide/) and [the command line](https://coil.zone/guide/cli/).
