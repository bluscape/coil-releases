Debugging the ESP32-S3 from Espressif-IDE gets as many breakpoints as you need and no more frozen IDE, and every debug session now leaves a log. VS Code updates the extension from the [Marketplace](https://marketplace.visualstudio.com/items?itemName=bluscape.coil) by itself.

**Tested with:** ESP32-C3, ESP32-S3 and ESP32-C6 over the chip's built-in USB-JTAG, and the classic ESP32 through an ESP-Prog. Windows 10 and 11 (x64).

## What's new

- **More than two breakpoints on the ESP32-S3 in Espressif-IDE** (or any GDB). The chip has two hardware breakpoints. From the third on, Coil writes a break instruction into the app in flash, as it already did in VS Code. A breakpoint is never refused. The newest gets a hardware slot and stops at once. One that has to wait in flash stops from the next reset, and GDB's console says so.
- **No more frozen Espressif-IDE.** Stop and Terminate no longer hang the IDE, Pause no longer ends in "Interrupt failed", and a board that loses power ends the session instead of leaving GDB waiting.
- **Faster resets with flash breakpoints:** Coil rewrites 4 KB at a time instead of whole blocks, under a second for the usual few.
- **Session logs** for VS Code and Espressif-IDE in `%LOCALAPPDATA%\Coil\logs`, each below 2 MB. Attach them to an issue when something goes wrong. `COIL_LOG=0` turns them off. The [guide](https://coil.zone/guide/#troubleshooting) has the details.
- **The firmware check** now also runs after flashing, so a board that didn't take the new build says so.
- **Fixed:** the clangd setup could write a `.clangd` that Espressif-IDE refuses to read ("expected a single document in the stream"), which broke its build.
- **Clearer USB-JTAG message** when Windows has given the board its generic WinUSB driver, which Coil can't reach. The message says how to fix it.

## Downloads

| File | For |
|---|---|
| `Coil-Setup-0.2.8.exe` | **Espressif-IDE.** Installs Coil per user and offers Espressif-IDE, ESP-IDF (through Espressif's installer, EIM) and the USB drivers when they're missing or out of date. Optional weekly update check. Run it over an earlier version to update. |
| `coil-0.2.8.vsix` | **VS Code without Marketplace access:** **Extensions → … → Install from VSIX**. Everyone else: install **Coil for ESP32** from the Marketplace or Open VSX. |

After installing for Espressif-IDE, set your debug configuration's OpenOCD **Executable path** to `%LOCALAPPDATA%\Programs\Coil\bin\coil-gdb.exe`. The [guide](https://coil.zone/guide/espressif-ide/) has the steps.

## Good to know

- This is a preview. Please [open an issue](https://github.com/bluscape/coil-releases/issues) with what you find.
- The programs aren't code-signed yet, so Windows SmartScreen may warn when you run the installer (**More info → Run anyway**). Code signing is the first [Ko-fi goal](https://ko-fi.com/coilzone).
