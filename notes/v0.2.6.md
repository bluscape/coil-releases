A clearer message when another program holds the ESP-Prog, and Coil is now on Open VSX. VS Code updates the extension from the [Marketplace](https://marketplace.visualstudio.com/items?itemName=bluscape.coil) by itself.

**Tested with:** ESP32-C3, ESP32-S3 and ESP32-C6 over the chip's built-in USB-JTAG, and the classic ESP32 through an ESP-Prog. Windows 10 and 11 (x64).

## What's new

- **An ESP-Prog in use by another program** (OpenOCD, another debug session, a serial terminal on its first COM port) is now named as busy. Before, Coil said its driver wasn't WinUSB and suggested reinstalling FTDI's driver, which didn't help.
- **On Open VSX:** VSCodium and other editors that use [Open VSX](https://open-vsx.org/extension/bluscape/coil) can install **Coil for ESP32** and get its updates there.

## Downloads

| File | For |
|---|---|
| `Coil-Setup-0.2.6.exe` | **Espressif-IDE.** Installs Coil per user and offers Espressif-IDE, ESP-IDF (through Espressif's installer, EIM) and the USB drivers when they're missing or out of date. Optional weekly update check. Run it over an earlier version to update. |
| `coil-0.2.6.vsix` | **VS Code without Marketplace access:** **Extensions → … → Install from VSIX**. Everyone else: install **Coil for ESP32** from the Marketplace or Open VSX. |

After installing for Espressif-IDE, set your debug configuration's OpenOCD **Executable path** to `%LOCALAPPDATA%\Programs\Coil\bin\coil-gdb.exe`. The [guide](https://coil.zone/guide/espressif-ide/) has the steps.

## Good to know

- This is a preview. Please [open an issue](https://github.com/bluscape/coil-releases/issues) with what you find.
- The programs aren't code-signed yet, so Windows SmartScreen may warn when you run the installer (**More info → Run anyway**). Code signing is the first [Ko-fi goal](https://ko-fi.com/coilzone).
