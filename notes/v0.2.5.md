Clearer messages from the serial tools, and a monitor that suits scripts. VS Code updates the extension from the [Marketplace](https://marketplace.visualstudio.com/items?itemName=bluscape.coil) by itself; the debugger and the JTAG flasher are the same as in 0.2.4.

**Tested with:** ESP32-C3, ESP32-S3 and ESP32-C6 over the chip's built-in USB-JTAG, and the classic ESP32 through an ESP-Prog. Windows 10 and 11 (x64).

## What's new

- **Flashing over a serial port (`coil-flash --port`)** says what to try when the chip doesn't answer: replug the board or hold BOOT (the chip's own USB port), or put it in download mode by hand (USB-to-serial boards). It also says when the port went away during the attempt.
- **A port another program holds** (a serial monitor, a log capture) is retried for a few seconds, then named as busy instead of "Access is denied". A port that isn't there says so, and that a replug can change its COM number. For `coil-flash` and `coil-monitor`.
- **`coil-monitor --reset`** resets the chip once the port is open, so the start-up lines show. Without it the monitor still joins a running board without resetting it.
- **`coil-monitor --duration <seconds>`** stops after that long, for scripts.
- **Plain text when piped:** `coil-monitor` leaves out colour codes when its output goes to a file or another program (`--color always` keeps them). VS Code's monitor keeps ESP-IDF's colours.
- **The OTA data line** says why it's written on each flash: firmware with OTA updates changes it while it runs, and flashing puts it back so the board boots the build you flashed.
- **ESP-IDF projects only, for now:** the Marketplace page and the guide say so. Arduino sketches (Arduino IDE, arduino-cli, PlatformIO) don't work with Coil yet; Arduino-ESP32 support is planned.

## Downloads

| File | For |
|---|---|
| `Coil-Setup-0.2.5.exe` | **Espressif-IDE.** Installs Coil per user and offers Espressif-IDE, ESP-IDF (through Espressif's installer, EIM) and the USB drivers when they're missing or out of date. Optional weekly update check. Run it over an earlier version to update. |
| `coil-0.2.5.vsix` | **VS Code without Marketplace access:** **Extensions → … → Install from VSIX**. Everyone else: install **Coil for ESP32** from the Marketplace. |

After installing for Espressif-IDE, set your debug configuration's OpenOCD **Executable path** to `%LOCALAPPDATA%\Programs\Coil\bin\coil-gdb.exe`. The [guide](https://coil.zone/guide/espressif-ide/) has the steps.

## Good to know

- This is a preview. Please [open an issue](https://github.com/bluscape/coil-releases/issues) with what you find.
- The programs aren't code-signed yet, so Windows SmartScreen may warn when you run the installer (**More info → Run anyway**). Code signing is the first [Ko-fi goal](https://ko-fi.com/coilzone).
