Espressif-IDE's **flash every time** now works with Coil: when a debug session starts, Coil flashes the project's build (writing only the 64 KB chunks that changed) before the IDE connects, so the session stops in your own `app_main`.

**Tested with:** ESP32-C3, ESP32-S3 and ESP32-C6 over the chip's built-in USB-JTAG, and the classic ESP32 through an ESP-Prog. Windows 10 and 11 (x64).

## What's new

- **Espressif-IDE:** Coil carries out the IDE's `program_esp_bins` startup command (its "flash every time" option), including build folders with spaces in their path. Before, Coil skipped it, the board kept its old firmware, and breakpoints such as `app_main` were never hit.
- **Clearer error when the debug configuration is for another chip:** Coil names the chip the configuration asks for, the boards that are connected, and what to change, instead of "no free ESP32-S3 board connected".

| File | For |

| `Coil-Setup-0.2.1.exe` | **Espressif-IDE.** Installs Coil per user and offers Espressif-IDE, ESP-IDF (through Espressif's installer, EIM) and the USB drivers when they're missing or out of date. Optional weekly update check. Run it over an earlier version to update. |

After installing for Espressif-IDE, set your debug configuration's OpenOCD **Executable path** to `%LOCALAPPDATA%\Programs\Coil\bin\coil-gdb.exe`. The [guide](https://coil.zone/guide/#espressif-ide) has the steps.
