Coil for ESP32 is on the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=bluscape.coil): search for **Coil for ESP32** in VS Code's Extensions view, and VS Code keeps it up to date from now on. The debugger, flasher and monitor are the same as in 0.2.3.

**Tested with:** ESP32-C3, ESP32-S3 and ESP32-C6 over the chip's built-in USB-JTAG, and the classic ESP32 through an ESP-Prog. Windows 10 and 11 (x64).

## What's new

- **VS Code Marketplace:** install with `code --install-extension bluscape.coil`, or from the Extensions view. If you installed an earlier `.vsix`, uninstall it and install from the Marketplace once, so VS Code updates it for you.
- **A Marketplace page written for users:** what Coil does, getting started, the debug options, and links to the [guide](https://coil.zone/guide/), the [benchmarks](https://coil.zone/benchmarks/) and the issues.
- **Windows x64 package:** the extension is marked as Windows-only, so VS Code on macOS and Linux doesn't offer it until Coil runs there.
- **Support Coil:** Coil is free. If it saves you time, you can [buy us a coffee or donate](https://ko-fi.com/coilzone) toward its upkeep; the extension's page in VS Code has a **Sponsor** button for it.
- **License:** Open VSX is named next to the VS Code Marketplace as an official place to get Coil.

## Downloads

| File | For |
|---|---|
| `Coil-Setup-0.2.4.exe` | **Espressif-IDE.** Installs Coil per user and offers Espressif-IDE, ESP-IDF (through Espressif's installer, EIM) and the USB drivers when they're missing or out of date. Optional weekly update check. Run it over an earlier version to update. |
| `coil-0.2.4.vsix` | **VS Code without Marketplace access:** **Extensions → … → Install from VSIX**. Everyone else: install **Coil for ESP32** from the Marketplace. |

After installing for Espressif-IDE, set your debug configuration's OpenOCD **Executable path** to `%LOCALAPPDATA%\Programs\Coil\bin\coil-gdb.exe`. The [guide](https://coil.zone/guide/espressif-ide/) has the steps.

## Good to know

- This is a preview. Please [open an issue](https://github.com/bluscape/coil-releases/issues) with what you find.
- The programs aren't code-signed yet, so Windows SmartScreen may warn when you run the installer (**More info → Run anyway**). Code signing is the first [Ko-fi goal](https://ko-fi.com/coilzone).
